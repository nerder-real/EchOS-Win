# EchOS-Win v1.0.5

修复「应用完全启动不了，双击图标没任何反应」。

## 修复

- **陈旧实例锁 + PID 复用会把应用彻底锁死**

  单实例锁 `instance.lock` 里存的是上次运行时的进程号。旧逻辑只判断
  「这个进程号现在有没有对应进程」，**不核对是不是 EchOS 自己**。
  而进程号会被系统回收再分配 —— 一旦锁里残留的旧进程号被别的程序占用
  （实际案例：撞上了 Edge 浏览器），启动时就误判「已经有一个实例在跑」，
  接着尝试唤起它、失败、**然后照样退出**。

  结果是双击图标毫无反应，而且会一直这样，直到那个进程号再次变化。

  现在改为核对进程映像名，确认这个进程号确实属于本程序才算「已有实例」；
  不匹配就视为陈旧锁并接管。已用真实进程号验证四种情况，包含本次出问题的那个。

  若遇到启动不了，手动删除 `%APPDATA%\EchOS\instance.lock` 即可立刻恢复。

## 说明

- 这个坑跟自动更新无关，是单实例判断本身的问题，只是恰好在更新后暴露出来
  （旧进程退出时没清掉锁文件）。
- 正常更新后看门狗日志在 `%TEMP%\EchOS_UpdateWatch.log`，
  应为 `alreadyRunning=1 relaunched=0`。
