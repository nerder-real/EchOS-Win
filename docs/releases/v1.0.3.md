# EchOS-Win v1.0.3

修掉更新时弹出的命令行报错窗口。

## 修复

- **更新过程中会闪一个命令行窗口并报一串错**：这是 v1.0.2 新增的「看门狗」
  （安装失败时负责把旧版重新拉起）写得有问题，两处原因：
  - 目录变量以反斜杠结尾，批处理里 `"%DIR%"` 的 `\"` 把闭合引号转义了，整行被拆坏；
  - 写出去的批处理是 UTF-8，cmd 按 GBK 解析，中文注释变成乱码并产生杂字符。
  
  现改为 PowerShell 实现，脚本纯 ASCII、引号全部交给 Dart 处理，两个坑都绕开了，
  并且以隐藏窗口运行，不会再有任何窗口弹出。

  顺带修了同类问题：PowerShell 是控制台程序，用「脱离控制台」的方式启动会直接
  起不来（实测 detached / detachedWithStdio 均不执行），已改为普通方式启动。

## 说明

- 更新本身**不受影响**：v1.0.2 的自动更新安装与启动都是正常的，
  这个报错窗口只是看门狗自身的噪音。
- 看门狗的作用：万一安装中止，把旧版重新拉起并再次提示更新，
  避免「旧版已退出、新版没装上、也没任何提示」的死局。
- 更新判定是「Release 标签版本 **严格大于** 应用自报版本」，版本相同不会提示。
