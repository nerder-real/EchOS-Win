# EchOS-Win v1.0.2

修复「点了更新，进度走完却什么都没装上」——静默安装的路径参数被二次转义，
安装程序在校验目录名时就中止了，一个文件都没写。

## 修复

- **自动更新实际没有安装任何文件**：给安装程序传目录时手写了引号
  （`/DIR="D:\Program Files\EchOS"`）。Dart 在 Windows 上拼命令行时会给含空格的
  参数自动加引号，已有的 `"` 又被转义成 `\"`，安装程序收到的是
  `/DIR=\"D:\Program Files\EchOS\"`，认为 `"` 是非法字符直接中止。
  日志里能看到「文件夹名称不能包含下列任何字符」并 `aborting`。
  现在去掉手写引号，交给 Dart 处理；顺带去掉路径结尾多余的反斜杠，避免同样的问题。
- **更新失败后应用一去不回**：静默安装是「本进程退出、交给安装程序接管」，
  一旦安装中止就变成「旧版已退出、新版没装上、也没有任何提示」。
  新增看门狗：等安装程序结束后若主程序没有起来，就把它重新拉起，
  最差情况也是回到旧版并再次提示更新，不会卡在死局。

## 说明

- 更新判定是「Release 标签版本 **严格大于** 应用自报版本」，版本相同不会提示。
- 安装版更新是静默覆盖安装，配置在 `%APPDATA%\EchOS`，不受影响。
- 安装过程日志在 `%TEMP%\Setup Log *.txt`，排查问题时可以直接看。
