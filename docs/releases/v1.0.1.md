# EchOS-Win v1.0.1

修复自动更新链路上的两个问题。

## 修复

- **更新检测到却不弹确认框**：启动时用的是静默检查（`silent: true`），而发现新版本后
  设置待更新状态的代码也被关在了 `if (!silent)` 里，导致「日志显示发现了新版本、
  界面却毫无反应」。静默只应用于屏蔽「已是最新 / 检查失败 / 未配置源」这类提示，
  发现新版本必须提示。
- **更新装完不自动重启**：静默安装（`/VERYSILENT`）不显示完成页，Inno Setup
  里带 `postinstall` 标志的启动项因此被跳过，新版装好后没人拉起。
  改为在 `ssPostInstall` 阶段显式启动；交互安装仍走完成页的复选框，两者互斥。

## 其他

- Release 标题统一为 `EchOS-Win <版本>`
- 发版说明改为读取 `docs/releases/<标签>.md`
- 本地构建脚本 `build_local.ps1` 默认版本号修正为 `1.0.0`
- 新增 MIT `LICENSE`

## 下载哪个

| 文件 | 说明 |
| --- | --- |
| `EchOS-Win-v1.0.1-x64-Setup.exe` | 安装版。写入「应用和功能」，推荐日常使用 |
| `EchOS-Win-v1.0.1-x64-Portable.exe` | 便携版。单文件自解压，免安装，适合 U 盘携带 |

## 说明

- 更新判定是「Release 标签版本 **严格大于** 应用自报版本」，版本相同不会提示，
  所以 v1.0.0 客户端会收到本次更新，v1.0.1 不会。
- 安装版更新是静默覆盖安装，配置在 `%APPDATA%\EchOS`，不受影响。
