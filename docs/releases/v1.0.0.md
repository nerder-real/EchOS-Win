# EchOS-Win v1.0.0

Windows 客户端的首发基线版本。

## 功能

- ECH（Encrypted Client Hello）+ TLS 1.3 隧道，握手阶段不暴露真实 SNI
- 简易 WebSocket 协议直连服务端（配套 Cloudflare Worker 见仓库 `worker/`）
- 本地分流：绕过中国大陆 / 黑名单 / 全局 / 自定义规则
- TLS 会话复用 + 多入口自动重试，单入口故障自动切换
- 系统托盘常驻、开机自启、分流模式热切换

## 下载哪个

| 文件 | 说明 |
| --- | --- |
| `EchOS-Win-v1.0.0-x64-Setup.exe` | 安装版。写入「应用和功能」，推荐日常使用 |
| `EchOS-Win-v1.0.0-x64-Portable.exe` | 便携版。单文件自解压，免安装，适合 U 盘携带 |

## 使用说明

- 首次启动会自动下载分流数据（geoip / geosite）到 `%APPDATA%\EchOS`，无需手动准备
- 客户端只在本机起 HTTP / SOCKS5 代理，**不启动 TUN 网卡**，不接管系统全局网络
- 便携版更新时通过父进程定位真实宿主并完成自替换，替换后自动重启
- 更新判定规则是「Release 标签版本 **严格大于** 应用自报版本」，版本相同不会提示

## 已知情况

- 分流规则依赖上游规则集，个别域名可能需要自行加自定义规则
- 服务端握手耗时受网络高峰影响，客户端在握不上时会自动换入口重试
